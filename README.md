# 泡泡龍 Bubble Shooter

用 Vue 3、Vite 和 TypeScript 寫的泡泡龍網頁遊戲，介面是繁體中文。

畫面全部用 HTML Canvas 繪製，音效全部用 Web Audio API 即時合成，沒有用遊戲引擎，也沒有任何圖片或音檔。手機可以直接用觸控玩。

## 玩法

- 在畫面上拖曳瞄準，虛線會畫出泡泡碰牆反彈的路徑，以及最後吸附的位置。放開手指或滑鼠就會射出。
- 指標拖到發射台下方再放開，可以取消這次射擊。
- 同色泡泡連在一起 3 顆以上就會消除。消除後沒有連到天花板的泡泡會一起掉落，每顆額外加分。
- 每一發都有消除就會累積連擊，倍率最高 ×5。只要有一發沒消除，連擊就歸零。
- 每射固定發數，天花板會往下壓一排。有泡泡越過底線就輸了，把場上泡泡全部清空就過關。
- 射出的顏色只會從場上還有的顏色裡抽。

| 計分項目 | 分數 |
| --- | --- |
| 消除一顆 | 10 × 連擊倍率 |
| 掉落一顆 | 20 × 連擊倍率 |

## 關卡

過關後會解鎖下一關。

| 關卡 | 名稱 | 顏色數 | 初始排數 | 天花板下降 |
| --- | --- | --- | --- | --- |
| 1 | 暖身 | 3 | 5 | 不下降 |
| 2 | 起步 | 3 | 6 | 每 20 發 |
| 3 | 漸進 | 4 | 6 | 每 18 發 |
| 4 | 加速 | 4 | 7 | 每 16 發 |
| 5 | 挑戰 | 5 | 7 | 每 15 發 |
| 6 | 密集 | 5 | 8 | 每 14 發 |
| 7 | 菱形 | 5 | 8 | 每 12 發 |
| 8 | 極限 | 6 | 9 | 每 12 發 |
| 9 | 心跳 | 6 | 9 | 每 10 發 |
| 10 | 最終關 | 7 | 10 | 每 8 發 |

第 7 關的泡泡排成菱形，第 9 關用愛心方程式排成愛心。

已解鎖的關卡、每關最高分和靜音設定都存在瀏覽器的 localStorage。最高分只有過關時才會記錄。

## 開發

需要 Node.js 和 npm。

```bash
npm install
npm run dev      # 開發伺服器；同一個區網的手機可以用終端機顯示的 Network 網址連線
npm test         # 單元測試（Vitest）
npm run build    # 型別檢查並打包到 dist/
```

核心邏輯放在 `src/game/grid.ts`，包含六角格、消除判定和射擊路徑，不依賴 DOM，單元測試都針對這一層。
